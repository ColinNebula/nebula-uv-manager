# Security Policy

## Supported Versions

Only the latest tagged release is supported for security updates.

## Reporting a Vulnerability

Please report security issues privately.

- Email: support@nebula3ddev.com
- Subject: Nebula UV Manager Security Report

Include:
- affected version
- Blender version and OS
- reproduction steps
- expected vs actual behavior
- proof-of-concept files (if safe to share)

## Disclosure Process

1. Report is acknowledged within 5 business days.
2. Issue is triaged and severity-assessed.
3. A fix is developed and validated.
4. A patched release is published.
5. Public disclosure is shared after users can update.
